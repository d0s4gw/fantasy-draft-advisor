# Data Subsystem — Quick Reference (`data/CLAUDE.md`)

Data Subsystem guide for `data/` folder. For full details, see [data/AGENTS.md](AGENTS.md).

- `config.json`: League settings & Governors list.
- `draft_state.json`: Saved picks & roster allocations.
- `sources.json`: Projection source weightings.
- `precomputed_gameplan.json`: Cached scouting notes.
- `sources/`: Folder holding input CSV files.
